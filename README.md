# 客服營運數位孿生平台 Demo

第二屆策略人才共識營提案競賽（第四組）的互動原型。資料皆為虛構，Jev 判斷結果以本機規則模擬，未連線任何真實系統。

- `index.html`：主 Demo，共 8 頁，依客戶旅程排列：客戶開口 → 電話接通 → 主管監控 → 數位孿生模擬。
- `ask.html`：評審參與頁。評審用手機掃 QR code，打一句話給客服，訊息會即時出現在主 Demo。

## 操作

- → 或點畫面空白處：下一頁；←：上一頁；數字鍵 1–4：跳到各步驟的第一頁；F：全螢幕。
- 右上角「評審參與」：顯示給評審掃描的 QR code。

## 評審參與的運作方式

手機頁把訊息送到 [ntfy.sh](https://ntfy.sh) 的一個隨機主題，主 Demo 每 2 秒輪詢一次取回訊息。
公司網路會擋即時串流和部分 POST，所以主 Demo 用輪詢，手機頁在 POST 失敗時改用 GET 送出。
網址加上 `?topic=自訂名稱` 可以換主題（主 Demo 與手機頁要一致）。
